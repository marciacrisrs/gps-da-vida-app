# Super Planner

App Android offline-first para organizar o dia, transformar intenção em ação e responder à pergunta **“o que faço agora?”**.

## Projeto

- Arquitetura: [ADR 001](docs/adr/001-arquitetura-inicial.md)
- Domínio: [ADR 002](docs/adr/002-modelo-de-dominio.md)
- Entrega: [WORKFLOW](docs/WORKFLOW.md)
- Design system: [design-system.md](docs/design-system.md)

Abrir a pasta no Android Studio, sincronizar o Gradle e rodar no emulador.

**Nome histórico:** GPS da Vida. O produto atual é Super Planner.
